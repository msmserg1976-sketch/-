# 🩺 Дневник давления

Веб-приложение для ведения дневника артериального давления и пульса с автоматической окраской показателей, группировкой по вахтам и экспортом в Excel.

## Возможности

- Ввод верхнего, нижнего давления и пульса
- Автоматическая окраска каждого показателя по настраиваемым порогам (низкое / норма / повышенное / высокое)
- Ручная отметка смены (день / ночь) и вахты (работа / отдых)
- Группировка записей по вахтам и месяцам
- Редактирование и удаление записей
- Автоматическая загрузка погоды (температура, осадки, атмосферное давление) через Open-Meteo по GPS или заданным координатам
- Экспорт в Excel (.xlsx) с поклеточной окраской показателей
- Настройка порогов цвета отдельно для верхнего, нижнего давления и пульса

## Как пользоваться

1. Открой приложение по ссылке GitHub Pages.
2. На вкладке «Ввод» добавь запись: дата, показатели, смена, вахта.
3. При первом сохранении разреши доступ к геолокации (или задай координаты в настройках ⚙).
4. На вкладке «Список» смотри записи, редактируй (✏️) или удаляй (🗑).
5. Кнопка «Экспорт в Excel» скачает файл с данными и цветовой разметкой.

## Технологии

- Чистый HTML + CSS + JavaScript
- [SheetJS (xlsx-js-style)](https://github.com/gitbrent/xlsx-js-style) — экспорт в Excel со стилями
- [Open-Meteo](https://open-meteo.com/) — погода по координатам и дате
- Данные хранятся локально в браузере (localStorage)

## Ограничения

- Данные хранятся в localStorage браузера — при очистке кэша они пропадут. Для резервной копии используй экспорт в Excel.
- Для работы геолокации нужен HTTPS (GitHub Pages подходит).
- Погода загружается только при наличии интернета.
